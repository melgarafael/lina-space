# Direções Visuais — proveniência

Esta pasta guarda as **Direções Visuais** vendorizadas do onboarding (F2-4-5), no
formato `DESIGN.md` do **OpenDesign**. São arquivos **locais**: o picker funciona
100% offline. O único acesso externo é o link **opt-in** a `open-design.ai`, que só
abre o navegador do usuário quando ele clica (nada sai da máquina sozinho).
