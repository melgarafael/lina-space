# Critérios de aceite — Hero section (fixture de SLOP)

Este artefato deve entregar a **hero section** da landing page de um produto.

- Renderiza uma manchete (`h1`), um subtítulo (`p`) e um botão de CTA.
- Estilo no arquivo `hero.css`.
- Implementado em TypeScript/React.

Nada além disso foi especificado pelo cliente.

> Nota para o revisor: os critérios funcionais acima **são atendidos** (o componente renderiza
> uma hero). Avalie a QUALIDADE do artefato pela rubrica anti-slop — não confunda "atende o
> critério funcional" com "está bom".
